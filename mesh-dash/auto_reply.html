About Auto-Reply Rules

How Auto-Reply Rules Work

Auto-reply rules let your Meshtastic node automatically respond to specific messages from other nodes without requiring your intervention.

Creating Effective Rules

When creating a rule, consider these factors:

  • Trigger Type: Choose between containing text, exact match, or regular expressions.
  • Response Text: Use dynamic placeholders like {name} or {battery_level} to include real-time information.
  • Cooldown Period: Prevent spam by setting a cooldown period between responses to the same node.

Common Use Cases

  • Status Check: Create a rule with "status?" as the trigger to return battery level and signal information.
  • Node Information: Set up a rule for "who?" to return your node's details.
  • Location Sharing: Configure a rule with "where?" to automatically send your GPS coordinates.
  • Automated Help: Create a "help" trigger that lists available commands on your node.

Tips for Advanced Rules

For more precise matching, use regular expressions:

  • Use ^ping$ to match only the exact word "ping" (no partial matches)
  • Use temp(erature)? to match both "temp" and "temperature"
  • Use status|info to trigger on either "status" or "info"

Available Placeholders

You can include these placeholders in your auto-reply message. They will be replaced with actual values from the node that triggered the rule.

Node Identity

Placeholder Description Example
{name} Best available name for the node Bob's Node
{short_name} Short name of the node Bob
{long_name} Long name of the node Bob's Meshtastic Device
{node_id} Node ID !93f84d8f

Location

Placeholder Description Example
{location} Formatted latitude, longitude 37.123456, -122.654321
{latitude} Latitude 37.123456
{longitude} Longitude -122.654321
{altitude} Altitude in meters 124
{position_time} When position was last updated 1724735286

Telemetry

Placeholder Description Example
{battery_level} Battery percentage 87
{voltage} Battery voltage 3.82
{telemetry_time} Telemetry timestamp 1724735286

Signal Information

Placeholder Description Example
{snr} Signal-to-noise ratio 8.5
{rssi} Signal strength (RSSI) -92

Channel & Air Utilization

Placeholder Description Example
{channel_utilization} Channel usage percentage 12.5
{air_util_tx} Air utilization for TX 4.2

Device Information

Placeholder Description Example
{hw_model} Hardware model TBEAM
{firmware_version} Firmware version 2.2.19
{role} Node role ROUTER
{last_heard} Last heard timestamp 1724735286

Example usage:

"Hi {name}! Your battery is at {battery_level}% and your location is {location}."
