About System Configuration

Configuration Settings

This section allows viewing and modifying settings stored in the .mesh-dash_config file.

Important: After changing any settings, you must restart the mesh-dash service for changes to take effect. Use the button that appears next to a saved setting. The page will attempt to reconnect and reload automatically.

Meshtastic Node Connection

  • Node IP Address - The IP address where your Meshtastic device can be reached. This must be correct for the dashboard to connect to your mesh network.
  • Node Port - The port number used by your Meshtastic device (typically 4403). Must match your device's configuration.

Web Interface Settings

  • Dashboard Host - The IP address where the dashboard listens for connections. Use 0.0.0.0 to allow access from any IP address, or specify a particular interface.
  • Dashboard Port - The port where the web interface will be available. Changing this requires updating any bookmarks or links to the dashboard.

Location Settings

  • Share Local Position - When enabled, allows this device to detect and share its GPS location on the MeshDash network.
  • Share Remote Positions - When enabled, allows this device to share position data from other connected nodes on the MeshDash network.

Using This Page

  • Edit values and click the button next to each entry to save changes.
  • After saving, a button will appear. Click it to restart the server and apply all saved changes.
  • Use "Refresh Config" to reload current values from the file.
  • If automatic reload fails after restart, you may need to manually refresh the page.
